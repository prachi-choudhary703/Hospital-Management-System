# Hospital Management System

A desktop-based Hospital Management System developed using Python, Tkinter and SQLite.

## About the Project

This is a desktop application developed to manage different hospital-related information from a single application.

The application provides a graphical interface using Tkinter and stores the data using SQLite.

## Technologies Used

- Python
- Tkinter
- SQLite
- SQL

## Features

- Login system
- Patient information management
- Doctor information management
- Nurse information management
- Worker information management
- Laboratory test management
- Room information management
- Total charges management
- Complaint management
- Suggestions management

## Database

SQLite is used to store and manage the application data.

The database file is created and managed by the Python application.

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/prachi-choudhary703/Hospital-Management-System.git
```

2. Open the project folder.

3. Run the application:

```bash
python hospital-management-system.py
```
