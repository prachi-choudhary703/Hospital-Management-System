# Hospital Management System

A desktop-based Hospital Management System made using Python, Tkinter and SQLite.

## About the Project

This is a simple desktop application developed to manage different hospital-related information from a single application.

The application provides a graphical interface using Tkinter and stores the data using SQLite.

## Technologies Used

- Python
- Tkinter
- SQLite
- SQL

## Features

- Login system
- Patient information management
- Doctor information management
- Nurse information management
- Worker information management
- Laboratory test management
- Room information management
- Total charges management
- Complaint management
- Suggestions management

## Database

SQLite is used to store the application data.

The database file is created and managed by the Python application itself.
